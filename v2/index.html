Project-first writing environment

เปิดมาเป็น Project และ Chat ก่อน

ผู้เขียนคุยกับ AI เหมือนแชทปกติ แต่ด้านหลังมีระบบ Project, Knowledge, Chapter, History, Theme, Font และ permission สำหรับ AI แยกไว้ชัดเจน

เข้าสู่ระบบ

Google เป็น provider หลักใน foundation นี้ ส่วน OAuth จริงจะต่อ backend ภายหลัง

สิ่งที่มีใน foundation นี้

  • Project → Chat เป็นจุดเริ่มต้น
  • Knowledge แยก source / status
  • Chapter มี version snapshot
  • History เก็บร่องรอยการเปลี่ยนแปลง
  • Theme และ Font แยกเป็นระบบ
  • AI access เป็นสิทธิ์แบบ project-scoped
  • Export / Import JSON พร้อมต่อยอด
